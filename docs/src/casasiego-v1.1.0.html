1 · Overview

Version 1.1.0 renames the house. Synodé becomes Casa Siego®, a registered trademark, and the site moves from synode.space to casasiego.com. The three brands keep their names (Fiel, Justo, Libre), now signed «by Casa Siego®». The visual system changes with the name: the parchment-and-ink Hellenic manuscript gives way to mostly white pages with vintage beige and wine bands, a two-typeface wordmark, a shared header with an animated mobile sidebar, and softer entrance animations on top of the existing parallax.

2 · Identity

Wordmark

CASA is set in Palacio, tracked at 0.2em in capitals; Siego in Ledger Regular; the ® sits small and high after Siego as the registration mark. Palacio is a licensed font that is not on Google Fonts: the site expects fonts/Palacio.woff2 (or .woff, .otf, .ttf) and falls back to Cinzel until the files are added. Ledger loads from Google Fonts on every page.

<p class="wordmark"><span class="wordmark__casa">CASA</span> <span class="wordmark__siego">Siego</span><sup class="wordmark__r">&reg;</sup></p>

Modifiers: .wordmark--hero (home), .wordmark--colophon (footers, terms). A ® after the name inside a heading uses <sup class="reg"> so it does not render full size in Bodoni.

4 · Shared chrome: js/casa.js

  • Header. Wordmark on the left, links on the right (Inicio, Fiel, Justo, Libre, Membresía, Contacto). Transparent over a dark hero, frosted white once the page scrolls, hidden while scrolling down and back on the way up. Pages that open on a light section get .head-offset so content sits below it. Links are built from the script's own URL, so one file serves every folder depth.
  • Mobile sidebar (≤ 900 px). Opens as a circle from the menu button. Its background starts at the colour of the section being read and eases into wine; touching or hovering a link tints it to that link's tone. Links slide in one after another; Esc, the scrim or a link closes it; focus moves in and back.
  • Section tones. As sections cross the middle of the screen the page background eases between white and beige (--tone on body).
  • Progress line. A 2 px wine line at the top tracks reading progress.
  • Reduced motion. All of the above falls back to static states under prefers-reduced-motion.

5.3 synode.space

Urgent synode.space still points at GitHub Pages (same four A records, www CNAME), but since the repository's custom domain became casasiego.com no repository claims it: synode.space and www.synode.space answer GitHub's «Site not found» 404. Old links, bookmarks and search results are broken until a redirect is in place. GitHub Pages cannot serve two domains from one repository, so the redirect must come from somewhere else:

OptionHowTrade-off
A · Cloudflare (recommended)Move synode.space's nameservers to Cloudflare (free); keep a proxied record; add a Redirect Rule: https://casasiego.com${http.request.uri.path}, status 301, preserve query string.True 301 on http and https, per path. Nameserver change takes up to 24 h.
B · Namecheap URL RedirectAdvanced DNS: delete the A and www CNAME records; add URL Redirect Record @ and www → https://casasiego.com, Permanent (301).Simplest. Check that https://synode.space redirects without a certificate warning, and whether paths are preserved.
C · Redirect repositoryNew repository (e.g. synode-redirect) with GitHub Pages, custom domain synode.space, and an index.html + 404.html that send every path to the same path on casasiego.com.Stays on GitHub with HTTPS, but the redirect is a page redirect, not an HTTP 301.

Keep synode.space registered and redirecting for at least a year so search engines and old links follow the move.

5.4 Search Console

  1. Add and verify casasiego.com (Domain property, DNS TXT record).
  2. Submit https://casasiego.com/sitemap.xml.
  3. Once synode.space returns 301 (§5.3), open the synode.space property → Settings → Change of address → casasiego.com.
