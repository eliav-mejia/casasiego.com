# fonts/ · Palacio (licensed)

The CASA half of the **CASA Siego®** wordmark is set in **Palacio**, which is not on Google Fonts.
Drop the licensed files here with these exact names (any subset works; woff2 first):

```
fonts/Palacio.woff2
fonts/Palacio.woff
fonts/Palacio.otf
fonts/Palacio.ttf
```

`css/site.css` (§0) and `docs/src/casa-siego-prelanzamiento.html` already point at them. Until they exist,
Cinzel stands in. **Siego** is Ledger Regular, loaded from Google Fonts on every page.
Check the Palacio licence allows web embedding (@font-face) before publishing.
